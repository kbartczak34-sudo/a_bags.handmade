# A-Bags Visual Customizer — Reference Layout V3

Acceptance target derived from the approved UI reference:

- desktop: step rail + focused configuration panel + dominant live preview,
- mobile: compact header + live preview + inspirations + accordion controls,
- exactly one visible interactive renderer at a time,
- active layers panel on desktop,
- real A-Bags reference thumbnails and inspiration presets,
- seven visual steps grouping handle/strap and hardware/accent,
- pricing remains sourced from the existing Bag Builder commerce settings and is never fabricated by layout code,
- Stripe/BLIK, validation, autosave, share link and checkout flow remain unchanged.
